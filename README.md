# Relic（レリック）

大学生のレポート作成・過去問管理を 1 つにまとめる Web アプリです。
Word を簡単にしたような編集画面（Note 風のボックス配置）＋ 数式入力 ＋ クラウドストレージ。

- メインカラー `#12C2D4` / ライト・ダークモード対応
- PC・タブレットは編集可、スマホ（幅 599px 以下）は閲覧のみ
- データは Firebase Realtime Database に保存（個人利用のためログイン機能なし）
- ビルド不要（HTML / CSS / ES Modules）。ライブラリは CDN から読み込み
  - Font Awesome 6（無料）/ KaTeX（数式表示）/ MathLive（数式入力）/ html2canvas + jsPDF + JSZip（出力）

## 構成

```
index.html            画面（ログイン・タブ・リボン・編集画面・ファイル）
Relic_icon.svg        アプリアイコン（未配置の場合は代替アイコンを表示）
css/style.css         アプリ UI・テーマ・メディアクエリ
css/doc.css           ドキュメント本体のスタイル（編集・出力共通）
js/app.js             起動・タブ切替・保存処理
js/firebase.js        Firebase 設定
js/storage.js         ストレージ（フォルダー/ファイル）の読み書き
js/editor.js          編集画面（ページ・ボックスの追加/移動/リサイズ・数式・画像・履歴）
js/textfmt.js         文字書式（フォント・囲み文字・フリガナ・行間・拡大縮小 など）
js/ribbon.js          リボン（ホーム/数式/レイアウト/表示）
js/filetab.js         「ファイル」タブ（開く/名前を付けて保存/出力/設定）
js/export.js          PDF・画像・HTML 出力、HTML 読み込み
js/find.js            検索・置換
database.rules.json   Realtime Database のルール（relic/ 以下を読み書き可）
```

データは `relic/nodes`（フォルダー/ファイル一覧）、`relic/docs`（本文）、`relic/settings` に保存されます。どの端末から開いても同じストレージが表示されます。

## セットアップ（Firebase コンソール）

1. **Realtime Database** → ルールに `database.rules.json` の内容を設定
   （または `firebase deploy --only database`）

> ⚠ ログインが無いため、データベースの URL を知っている人は誰でもデータを読み書きできます。
> 公開 URL を他人に共有しないでください。

## 起動

ES Modules を使うため `file://` では動きません。ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。Firebase Hosting に公開する場合：

```bash
firebase deploy
```

## 主な機能

| タブ | 内容 |
| --- | --- |
| ファイル | ストレージ（フォルダー作成・名前変更・移動・コピー・削除・PDF 化・ドラッグ＆ドロップ）、新規 / 開く（HTML 読み込み）/ 名前を付けて保存 / 上書き保存 / コピーを作成 / 出力（PDF・画像・HTML、A3/A4/A5/B4/B5、ページ指定、保存先選択）/ 設定 |
| ホーム | フォント、太字・斜体・下線・取り消し線、指数・添え字、サイズ、色（RGB 任意）、蛍光ペン、囲み文字（○□△◇・右クリックで詳細設定）、フリガナ、揃え、箇条書き・段落番号・アウトライン、文字の拡大縮小、線、行間（相対値/固定値）、ボックスの色、挿入、検索・置換 |
| 数式 | 数式ボックス、構造テンプレート（分数・根号・積分・総和・極限・行列…）、記号、ギリシャ文字、数式キーボード、LaTeX 直接編集 |
| レイアウト | 余白（既定：上 35mm・他 30mm）、向き、用紙サイズ、ページの追加/削除 |
| 表示 | ズーム、ページ幅に合わせる、余白ガイド、グリッド線、テーマ |

### 編集画面の操作
- ページ上にカーソルを動かすと「＋」が表示され、テキスト / 数式 / 画像を追加できます
- ボックスは左上のつまみ・枠線をドラッグで移動、ハンドルでサイズ変更（画像は四隅で縦横比維持、Shift で自由変形）
- ボックスは重ねて配置でき、右クリックで前面/背面・複製・色・削除
- 数式ボックスはダブルクリックで編集
- ショートカット：Ctrl+S 上書き保存 / Ctrl+Shift+S 名前を付けて保存 / Ctrl+F 検索 / Ctrl+H 置換 / Ctrl+Z・Ctrl+Y 元に戻す・やり直し / Delete ボックス削除 / 矢印キーで移動

## メモ
- 画像はドキュメント内に埋め込み保存されます（長辺 1600px に自動縮小）。
- 「保存先の選択」は File System Access API 対応ブラウザ（Chrome / Edge）で有効です。その他のブラウザではダウンロードフォルダーに保存されます。
- MS 明朝がない環境（Mac / スマホなど）では Noto Serif JP 等で代替表示されます。
